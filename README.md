# Sistemas Adaptativos Inteligentes · CAETI

Presentación web interactiva para una exposición de 15 minutos sobre la plataforma experimental del CAETI y sus proyectos de investigación.

## Controles

- Flechas izquierda y derecha, barra espaciadora o Page Up/Page Down para navegar.
- Tecla `F` para activar pantalla completa.
- Clic en los códigos o fichas de proyectos para ver dirección, equipo y línea de investigación.
- Tecla Escape para cerrar una ficha.

## Desarrollo local

```bash
npm install
npm run dev
```

La presentación utiliza React, TypeScript y Vinext. Las capturas y fotografías se encuentran en `public/`.
